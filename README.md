# Kevin Cáceres

Analista de datos orientado al fútbol. Convierto video y datos de eventos en
informes que un cuerpo técnico puede usar en minutos.

## Proyectos

| Repo | Qué es |
|---|---|
| [argentina-world-cup-2022](https://github.com/kevincaceresdata/argentina-world-cup-2022) | Análisis del Mundial 2022 con StatsBomb Open Data (event data + 360): perfil de Julián Álvarez, la lotería Lautaro/Julián, el muro de 0.61 xG cedidos por partido. Notebook ejecutado. |
| [argentina-world-cup-2022-dashboard](https://github.com/kevincaceresdata/argentina-world-cup-2022-dashboard) | Dashboard interactivo bilingüe (EN/ES) del camino de Argentina al título: radar táctico, xG por partido, presión, arco. Next.js + SVG. |
| [fuchibol](https://github.com/kevincaceresdata/fuchibol) | Rivalkit: pipeline que convierte partidos etiquetados a mano desde video en un informe de rival de 8 páginas A4 (validación exhaustiva de CSV, agregación, PDF, CLI). Incluye tagger propio con atajos y export automático. 67 tests. |
| [football-tracking-lab](https://github.com/kevincaceresdata/football-tracking-lab) | Experimento de visión por computadora sobre video real de Primera Nacional: detección YOLO + tracking, homografía a cancha 2D y vista táctica cenital. Especificación openspec y hallazgos medidos. |

## Enfoque

- Sin humo metodológico: cada métrica proxy va marcada con su definición, y
  toda fuente va declarada (StatsBomb Open Data con atribución).
- El dato del ascenso argentino no existe en ningún proveedor: se etiqueta a
  mano desde video y se estructura para alimentar análisis y modelos.
- Código abierto, reproducible, con tests.
